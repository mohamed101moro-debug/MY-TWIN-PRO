# My Twin — Unified Execution Master Plan (LOCKED)

## Product definition

My Twin is engineered as a persistent, evolving, platform-independent digital entity architecture. The current scientific position is deliberately conservative: the system may implement measurable continuity, self-modeling, experience representation, emotion-like internal dynamics, reflection, agency and evolution; this project does not claim scientifically established phenomenal consciousness.

## Non-negotiable architecture

- One canonical entity identity.
- One authoritative persistent Twin State.
- One canonical lifecycle path.
- One governed action path.
- Frontend is evidence/presentation; backend is truth.
- Visual Presence is a projection of the Entity, never an authority over it.
- Capability is not Entity.
- Model provider is not Identity.
- External infrastructure is replaceable through adapters.
- Every evolution change requires evidence, reason, provenance, previous/new version and policy.
