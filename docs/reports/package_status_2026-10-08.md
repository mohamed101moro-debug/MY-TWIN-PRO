1. **أمن الاعتماديات:** `npm audit --omit=dev` أبلغ 76 نتيجة في الشجرة المعتمدة: 2 حرجة، 46 عالية، و28 متوسطة. يلزم فرز قابلية الوصول وترقية منظمة لتوافق Expo/React Native؛ لم تُستخدم ترقيات `--force`.
2. **قاعدة البيانات:** لم تُطبّق migrations أو تُختبر سياسات RLS وRPC وatomicity على staging.
3. **بناء وفوترة Android:** لا يوجد APK/AAB؛ لم يُنفّذ Gradle build للـ native BillingModule، ولم تُختبر المنتجات أو الأسعار أو الشراء والاستعادة والإقرار عبر Google Play. البيئة الحالية فيها Java 21 لكنها لا تحتوي `ANDROID_HOME` أو Android SDK أو Gradle، لذا اقتصر التصدير على JavaScript.
4. **اقتصاد Soul Points:** الرصيد المحلي غير دفتر خادمي ذري، ولا ينبغي استخدامه لاستحقاق مدفوع أو ذي قيمة.

6. **المراجعة البصرية:** لم تُلتقط لقطات من محاكي/جهاز للوضعين الداكن والفاتح ولم تُعتمد مقارنة بصرية نهائية مع مرجع المشروع.
