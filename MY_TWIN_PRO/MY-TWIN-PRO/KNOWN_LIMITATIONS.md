# Known Limitations

**التاريخ:** 2026-11-05

الحالة الحالية ليست جاهزة للإطلاق العالمي. عنوان Railway الرسمي يجيب حالياً بواجهة `qaddaha-web`؛ مسارات My Twin API تعيد HTML أو 405 بدلاً من JSON، لذلك لا يمكن اعتبار `Failed to fetch` مغلقاً حتى يُنشر Backend My Twin على نفس الخدمة أو يُضاف proxy صحيح.

المصادقة الحالية تحتاج إغلاقاً إنتاجياً: التسجيل يفعّل تأكيد البريد إدارياً، وعميل التطبيق يكرر التوكن في AsyncStorage بدلاً من SecureStore، وطبقة المصادقة لا تفرض حالة `profiles.status == active` قبل السماح بالوصول. هذه البنود تبقى P0.

اختبار pytest الكامل ما زال يحتوي اختبارات legacy غير قابلة للجمع: `test_api_routes.py` يحتاج أسرار Supabase، و`test_memory_engine.py` يستورد وحدة قديمة غير موجودة. الاختبارات المركزة التي تحمي الاستمرارية والتحديات تمر، لكن لا يجوز تسمية suite الكاملة خضراء حتى تُرحّل أو تُصلح هذه الاختبارات.

لا توجد بعد أدلة staging مستقلة لـRLS، حذف/تصدير كامل، Billing sandbox، EAS preview على جهاز حقيقي، أو Gates B–E التشغيلية. لا ينبغي تنفيذ SQL إنتاجي أو إعلان إطلاق قبل توفير هذه الأدلة.
